# DRONE SYPHON

Side-view expedition. Your pack is dying. Launch the harvest drone, steal a little power, ride farther than you should.

Not GRIDRUNNER. New repo, 2D, one verb: **syphon**.

## Play the v0 strip

Open `index.html` from a local static server (not a `file://` URL):

```bash
python3 -m http.server 8000
```

Then http://localhost:8000 — **A/D** ride · **F** launch/dock · **E** drink on the lime panel · **space** hop.

Phone buttons are on the bottom.

Gate opens when trailer ≥ 18.
